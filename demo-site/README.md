# Demo Site

> ⚠️ Intentionally vulnerable. Do not deploy publicly. For local security testing only.

This is a self-contained Vite frontend for a small-business site. It uses an in-memory mock API so all pages and dashboard flows work without a server or database. Data resets when the browser refreshes.

Run from the repository root:

```powershell
npm run install:all
npm run dev
```

Open `http://127.0.0.1:5173`.
